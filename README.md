## 页面规范

新页面编写规范见 [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md)（沿用 hw-protocols 的规范）。
两点与本站相关的差异：

- 跨页导航脚本是 `docs/component-nav.js`（器件站版本，抽屉标题「全部器件」），页面 `</body>` 前引入 `<script src="component-nav.js" defer></script>`。
- 新器件上线时在 `component-nav.js` 的 `COMPONENTS` 数组里加一项，全部页面自动同步；首页卡片同步更新 `docs/index.html`。

## 本地预览

页面均为纯静态 HTML，无需构建：

```bash
cd docs && python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

双击单个 `docs/*.html` 以 `file://` 方式打开同样可完整运行（仅 Google Fonts 依赖网络，离线时回退系统字体）。
