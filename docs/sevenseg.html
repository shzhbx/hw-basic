数码管SEVEN-SEGMENT & DISPLAY

最古老的「屏幕」：把 8 颗 LED 塞进一片玻璃，排成 8 字加一个小数点，点亮不同组合就是 0–9 与半个字母表。 它看似简单，实则是LED 阵列的退化形态——于是所有阵列的功课它全要补：限流、极性、动态扫描、鬼影、峰值电流。 一个 4 位数码管用 12 个 IO 还是 3 根线？答案都在「分时复用」四个字里。 往下滚动：段码构建实验室、共阴/共阳电流路径、引脚判别侦探、动态扫描+鬼影实验室、限流计算器、四种驱动电路、0–F 字符画廊。

01

它是什么，为什么需要它

What & Why

数码管（seven-segment display，七段显示器）是专门用来显示数字与少量字符的 LED 阵列： 七个条形 LED（国际惯例命名 a–g）按「日」字形排布，加右下角小数点 dp，共 8 颗。 要显示「4」，就点亮 b c f g 四段——一组亮灭组合叫一个段码（segment code）。

它 1970 年就出现在计算器上，比 LCD 便宜、比 OLED 皮实、自带 1–5 米外可读的亮度， 至今仍是万用表、电饭煲、充电宝、电梯楼层屏的主力。对嵌入式工程师， 它是绕不开的一课：一个人位数不多的项目里，「显示 4 个数字」这件事足以把 限流、极性、IO 复用、驱动芯片选型四门课全部考一遍。

多位数码管（2/3/4 位一体）内部把所有位的同一段连在一起：位 1 的 a 段和位 2 的 a 段共用一根引脚。 于是 4 位管只要 8 根段线 + 4 根位选线 = 12 个 IO，而非 32 个——代价是同一时刻只能点亮一位， 靠动态扫描轮播欺骗眼睛（05 节实验室）。这就是「分时复用」，键盘矩阵扫描是同一招。

电气上，每一颗段 LED 与普通 LED 没有任何区别：VF 按颜色（红 2.0V / 绿 2.2V / 蓝 3.2V）， 必须限流，反接不亮。二极管页讲过的所有 LED 规则原样适用，本页只补「阵列」特有的部分。

SPEC · 01

正向压降 VF

按 LED 颜色：红 2.0V、黄 2.1V、绿 2.2V、蓝 3.2V。限流电阻按它算：R=(VCC−VF)/I。蓝色管在 3.3V 系统余量仅 0.1V，几乎点不亮（10 节踩坑 ⑤）。

SPEC · 02

尺寸 0.28″–4″

字高（英寸）。0.28/0.36 是仪表常客，0.56 是开发板四位一体常见尺寸，1 英寸以上要考虑驱动电流翻倍。

SPEC · 03

发光强度 mcd

毫坎德拉。红管典型 1–3mcd@10mA，超高亮红 20mcd+。户外屏选高亮管并提高峰值电流，别硬拉平均电流。

SPEC · 04

峰值电流 If(peak)

数据手册给的脉冲上限（典型 70–150mA，占空比 1/10、脉宽 ≤1ms）。动态扫描的峰值电流按它卡，不是按连续 20mA。

GLYPH

一个字形 = 一组段

SEGMENT CODE
习惯上把 8 段压进一个字节：bit7…bit0 = dp,g,f,e,d,c,b,a。「0」= abcdef = 0x3F，「8」= 全亮 = 0x7F，加 dp 再或上 0x80。整字查表，一位一个字节。
DUPLEX

多位的本质是复用

MULTIPLEX
位内 8 段并联成「段总线」，位与位之间同段共享。任一时刻只拉通一位的公共端，12 个 IO 就够 4 位——轮换速度够快（全刷新 ≥50Hz），眼睛看到的就是 4 位同时亮。
SCAN

眼睛是最后的显存

PERSISTENCE
LED 熄灭后，视觉亮度还要几十毫秒才归零。扫描周期必须比余辉短：全刷新 ≥50Hz 是底线，工程上取 100–200Hz（每位驻留 1–2ms）。相机拍出滚动条纹正是扫描的证据。
02

段码构建实验室

Segment Code Lab

点亮/熄灭下面的段，右侧实时生成共阴/共阳两套段码——这就是你 MCU 里那个 SEG_FONT[] 数组的每一项。 快捷键直接载入 0–F 等现成字形；注意 共阳码 = 共阴码按位取反（0x3F ⇄ 0xC0），两套表差一个 ~。

字节序 bit7…bit0 = dp g f e d c b a
怎么读：「0」= a b c d e f 六段 → 二进制 0011 1111 → 共阴 0x3F。 同一字形在共阳管里要点亮的段完全一样，只是引脚电平取反，所以机器码按位取反得 0xC0。 表格请按「芯片 + 管型」二选一刻进 Flash，运行时查表最快。
03

共阴与共阳：一管两制

Common Cathode / Anode

8 颗 LED 总要各接出一端到公共点——阴极并联就是共阴（CC），阳极并联就是共阳（CA）。 外观完全一样、丝印只差后缀（如 5011 共阴 / 5011BS 里 BS 常表共阳），买错就全灭或微亮。 点下面的步进，看同一颗 b 段 LED 在两种管子里的电流怎么走。

CC共阴管COMMON CATHODE
公共端接 GND，段脚给高电平点亮（经限流电阻）。适合「IO 拉电流 → LED → 地」的低边思路； 段码正逻辑：写 1 亮。0x3F 显示「0」。
CA共阳管COMMON ANODE
公共端接 VCC，段脚给低电平点亮——MCU 引脚灌电流路径。多数 MCU 灌能力 > 拉能力， 且高边直接挂电源，所以市售模块共阳居多。段码负逻辑：0xC0 显示「0」。
GPIO

拉电流 vs 灌电流

SOURCE / SINK
同一颗 IO，「往负载里推电流」与「从负载里收电流」的极限不同，数据手册分别叫 IOH / IOL。 共阳管走灌路径，往往能点亮得更足——这就是「高边挂电源」流行的电气原因（不白占便宜）。
CHIP

驱动芯片常常只认一种

POLARITY LOCK-IN
扫描驱动芯片的位选输出极性是焊死的：MAX7219 只配共阴，TM1637 面向共阳。选型顺序应是「先定驱动芯片，再按它买单/布数码管」，反过来会多焊一层反相三极管。

动态扫描与鬼影实验室

Multiplex & Ghosting Lab

上半是真实的 4 位管（带视觉余辉模型），下半是逻辑分析仪：4 根位选线 + 1 根段总线（把 8 位段码按电压铺开）。 拖刷新率滑杆看余辉跟不上时哪里先闪烁；打开「鬼影时序」看切换顺序错误时邻位怎么串进半截字。 正确顺序永远是：消隐 → 换段码 → 开位选。

选型五步与实战代码

Selection & Code
1

定颜色与 VF，先过电压关

3.3V 系统别选蓝色管（VF 3.2V，余量 0.1V 点不亮）；红/绿安全。5V 系统全颜色可选。

2

定极性：跟着驱动芯片走

用 TM1637 → 共阳；用 MAX7219 → 共阴；纯 GPIO → 共阳吃灌电流红利。别先买管后配芯片。

3

定位数与尺寸

需要小数点/冒号（时钟）？确认 dp/colon 引脚存在。0.36″ 一米外可读，1″ 以上考虑分段提高电流。

4

算电流账，选驱动档位

1 位 GPIO 直驱；2–4 位三极管/ULN2003 位驱动 + 段串阻；≥4 位或要省 IO → TM1637/MAX7219/HT16K33。06 节计算器过一遍。

5

查引脚图，画段映射表

一体管引脚没有统一标准，COM 常在中间两脚但段序随机。按 04 节方法实测建 SEG_PIN[] 映射，别照抄别人的表。

arduino · TM1637（两线 · 共阳 4 位）
// Library: TM1637Display（avishorp）· CLK/DIO 任意两个 GPIO
#include <TM1637Display.h>
TM1637Display disp(CLK_PIN, DIO_PIN);

void setup() {
  disp.setBrightness(7);          // 0–7：内部 16 级 PWM 调占空比
  uint8_t seg[] = { 0x4F, 0x86, 0x66, 0x06 };  // 3 . 1 4 1（dp=0x80）
  disp.setSegments(seg);        // 芯片内置扫描，MCU 只写一次显存
}
stm32 · 裸 GPIO 动态扫描（TIM 中断换位）
// 段: PB0-PB7 = a..dp（共阴正逻辑）· 位选: PA4-PA7 经 NPN
const uint8_t FONT[10] = {0x3F,0x06,0x5B,0x4F,0x66,
                            0x6D,0x7D,0x07,0x7F,0x6F};
volatile uint8_t digits[4] = {3,14,1,4};  // 3.141

void TIM2_IRQHandler(void) {          // 2ms 一拍 = 全刷新 125Hz
  static uint8_t pos = 0;
  GPIOA->BSRR = dig_mask[pos];       // ① 消隐+关旧位（先拉低）
  GPIOB->ODR  = FONT[digits[pos]];   // ② 换段码
  GPIOA->BSRR = dig_mask[pos] << 16; // ③ 开新位——顺序反了就出鬼影
  pos = (pos + 1) & 3;
}
linux · gpiod 扫描线程（无驱动芯片时）
# 4 位共阳：段 gpioset 拉低点亮 · 位选经 NPN
while : ; do
  for i in 0 1 2 3; do
    gpioset --mode=exit $(dig $i)=0          # 消隐（关所有位）
    gpioset --mode=exit $(seg ${D[i]})       # 段总线 = 共阳反码 ~FONT
    gpioset --mode=exit $(dig $i)=1          # 开当前位
    sleep 0.002
  done
done  # 实时性不足会闪烁——正式产品请用驱动芯片或内核扫描驱动

踩坑指南

Pitfalls

八条高频翻车现场，每条都对应本页某个实验室里的红色演示。

PIT · 01

鬼影：邻位渗出半截字

换位时段码先变、位选后关，旧位在 0.3ms 里显示了新位的开头段。表现为「3」旁边有淡淡的「1」。 修法：消隐 → 换段码 → 开位选三步走（05 节右侧时序开关）。

PIT · 02

亮度不均：1 比 8 暗 / 位间亮度漂移

把限流电阻放在位选一侧共用：亮 2 段的「1」压降小电流大、亮 7 段的「8.」电流被摊薄——段数越多越暗。 修法：电阻放段侧每段一只（8 只），位选只过开关管。

PIT · 03

峰值电流超限：扫描把电流乘了 N

4 位扫描占空比 25%，同亮度需峰值 ×4；位选电流 = 点亮段数 × 段电流（「8.」= 7×10mA = 70mA），直接进 GPIO 必超 25mA 红线。 修法：位选一律经三极管/ULN2003，段峰值按手册 If(peak) 卡。

PIT · 04

共阴共阳搞反：全灭或整管微亮

共阳管按共阴接线：所有 LED 反偏——全灭；段码也反了，即便接对电平也是「亮的全亮、灭的全灭」一片红。 修法：上电前按 04 节二极管挡判一遍；代码里加 #define CA 统一取反。

PIT · 05

3.3V 点蓝色管：电路全对就是不亮

蓝/白 LED VF≈3.2V，3.3V 减去后只剩 0.1V 给电阻——电流不到 0.3mA，勉强见幽光。 修法：换红/绿管，或上 5V/升压，或用带电流源的驱动芯片。

PIT · 06

dp 微亮：没接的小数点在发光

dp 脚悬空时，相邻走线耦合 + IO 漏电流足以让它在暗室可见，产品夜间返修主因之一。 修法：不用的 dp 段脚接 GND（共阳）或加下拉，别悬空。

PIT · 07

闪烁 / 相机条纹：刷新率掉到 50Hz 以下

中断被长任务压住、或 Linux 用户态扫描抖动，全刷新率跌破 50Hz：肉眼闪、手机拍出滚动黑带。 修法：定时器中断保证节拍；Linux 上用驱动芯片让硬件自己扫。

PIT · 08

引脚图想当然：照抄别家的段映射

同是 0.56″ 4 位管，不同厂家段序、COM 位置都不同；「中间两脚是 COM」只是惯例不是标准。 修法：04 节方法 5 分钟实测建表，写进 SEG_PIN[] 再动代码。
