麦克风MICROPHONE & MEMS

扬声器页把「电→力→声」走了一遍，麦克风把这条链整个倒过来跑：声压推振膜， 音圈在磁场里运动，e = B·L·v——法拉第定律让声音直接发电。驻极体（ECM）用一层永久带电的薄膜省掉 48V 幻象电源， 一颗 2.2kΩ 偏置电阻就让它统治了三十年嵌入式拾音；如今 MEMS 把振膜刻进硅片， 出厂就是 PDM / I2S 数字流——连 ADC 都省了。 往下滚动：换能原理步进实验室、灵敏度声学账本计算器、ECM 读放电路实验室（偏置/耦合/削波/差分）、PDM 码流实验室、指向性极坐标，以及真的能点亮你电脑麦克风的实时采声实验室。

01

它是什么，为什么需要它

What & Why

麦克风（microphone，业内也叫 mic / 咪头 / 拾音器）是声电换能器：把空气的振动变成电压的振动。 你的设备要「听得见」——语音唤醒、声控灯、噪声监测、通话降噪——第一步都是它。 和扬声器一样，它是少数每天与模拟世界打交道的器件：输入是 20µPa 起步的声压，输出是毫伏级电压， 中间隔着整个「小信号 + 高增益 + 抗干扰」的模拟艺术。

两大家族分野在换能物理量：动圈式用电磁感应（e = B·L·v，扬声器的亲兄弟，话筒线圈在磁隙里当发电机）； 电容式用极板间距变化（C = εA/d）把声压变成电容调制，再变成电压。录音棚电容麦需要 48V 幻象电源建立电场， 而驻极体（electret condenser microphone, ECM）把电荷永久冻在氟化聚合物薄膜里——电场白送， 只需 2–10V 给内置的 JFET 阻抗变换器供电，于是两根引脚 + 一颗电阻就是一个拾音前端。

嵌入式今天的答案是 MEMS 麦克风：硅刻蚀的振膜 + 背腔 + 内置 ASIC，输出模拟差分、PDM 或 I2S。 芯片尺寸 3×4mm、可回流焊、一致性好——手机、智能音箱清一色 MEMS。选哪种界面是系统级决策： 模拟要自己搭 ADC 前级，PDM 只需一路时钟 + 一根数据线，I2S 则像挂了一颗音频 codec。

关键认知：麦克风的输出小得可怜。典型 ECM 灵敏度 −38 dBV/Pa：94dB 的正常喊话只输出 12.6mV RMS， 距离 ADC 的 1V 级满量程还差 40dB——拾音链的本质是「低噪声放大 100 倍」的工程，本页 §03 计算器和 §04 电路实验室都在算这笔账。

SPEC · 01

灵敏度 −38 dBV/Pa

94dB SPL（1 Pa）输入时的输出电压。−38dBV = 12.6mV；每差 6dB 电压差一倍——灵敏度是整条增益链的起点账。

SPEC · 02

信噪比 SNR 58–65 dBA

94dB SPL 信号与自身底噪（A 计权）之差。ECM 约 58–62dB，好 MEMS 65dB+——安静环境听写才不掉字。

SPEC · 03

指向性 POLAR

对哪个方向灵敏。ECM/MEMS 的振膜小、声学路径对称，天生全向；心形指向要双进声孔或阵列波束成形（06 节）。

SPEC · 04

供电 2–10V / 1.8–3.6V

ECM 经 Rbias 从信号脚「蹭电」（典型 0.5mA）；MEMS 是正经 VDD——有的 PDM 型号严格 1.8V，接 3.3V 会永久哑掉。

02

换能原理实验室 · 声压怎样变成电压

Transduction Lab

声音是空气的纵波：分子被挤密又拉开，瞬时声压围绕大气压上下起伏。麦克风要做的只有一件事—— 让这团起伏去推一块很轻的振膜，再把振膜的位移换成电。点下面四步，看动圈式怎么用 e = B·L·v 发电， 再看电容式怎么用 ΔC 调制电荷。

DYNAMIC

动圈 · 扬声器倒着用

e = B·L·v
同一颗器件正着用是扬声器、反着用是话筒——对讲机的喇叭麦一体方案正是这么干的。动圈输出阻抗低（几十–几百 Ω）但灵敏度只有 1–2 mV/Pa，比 ECM 低 10–20dB，需要干净的话放才堪一用。
ELECTRET

驻极体 · 冻住的电荷

C = εA/d
驻极体薄膜上的电荷半永久不跑（100 年衰减几个 %），背极板与振膜构成 ~15pF 的小电容：声压改变间距 d → C 变化 → 高阻节点电压波动。吉欧级源阻抗必须先过 JFET 阻抗变换才能出门——这就是 ECM「必须给电」的原因，也是它两脚有极性的原因。
MEMS

MEMS · 刻在硅上的振膜

SILICON MIC
振膜、背极板、背腔、放大器、ΣΔ 调制器全部封进 3×4×1mm 的表贴封装，底部或顶部一个进声孔（选封装时先看声孔朝向！）。一致性极佳：同一型号灵敏度散布 ±1dB，而 ECM 要 ±3dB——双麦阵列波束成形只能用 MEMS。
SCALE

声压的数量级

20 µPa → 20 Pa
0dB SPL 是人耳听阈（20µPa），94dB 是 1 Pa——灵敏度规格点；对话 60–70dB，地铁 100dB，喷气机 130dB。整个可听范围 1:10⁶，所以音频链路里说增益永远用 dB：每 20dB = 电压 ×10。

Sensitivity & Bias Math

「最大声压时削波，小声时听不见」的解法不是把增益拧到刚好，而是让最大预期声压落在 −6…−10 dBFS： 峰值因子（crest factor）的人声在 12–18dB，正弦满幅 ≠ 语音满幅。偏置同理：Vdc 逼近任何一条轨， 半个波形先削——47kΩ 偏置在 3.3V 下工作点掉到地，就是 04 节场景①的「贴地死」。耦合 fc 别卡在需求下限上， 人声 300Hz 的系统用 fc ≤ 100Hz 的一阶高通才不至于低频相位发闷。

04

ECM 读放电路实验室 · 四个必懂的接法

Readout Circuits

一颗两脚 ECM 从「会振的电容」变成「ADC 能吃的信号」，要过四关：偏置电阻（工作点坐哪儿）、耦合电容（直流往哪隔）、 增益档位（削波与底噪的平衡）、差分接收（MEMS 时代的新功课）。切换场景与模式——左边电路在走流， 右边示波器在算波形，读数全部由模型实时生成。

偏置坐中 · 隔直再放大BIAS MID · COUPLE THEN GAIN

ECM 的 JFET 是漏极开路输出：Rbias 不只是供电，它和静态电流一起决定工作点 Vdc = VDD − Id·R（04 节场景①）。 交流信号骑在这个直流上，所以进放大器之前必须经 Cout 隔直、在下一级重新偏置到中轨（场景②）——省掉它的代价是把 2.3V 直流也放大 8 倍，输出直接顶死电源轨。 增益预算用 03 节计算器算好再定 Rf/Rg（场景③）；上 MEMS 后改考差分接收：只接一半 = 幅度减半 + 共模噪声全额（场景④）。

05

MEMS 三界面与 PDM 码流实验室

MEMS Interfaces & PDM Lab

同一颗硅振膜，ASIC 出口不同就是三种器件：模拟（差分/单端，进 ADC）、PDM（1bit 高速码流，主控抽取）、 I2S（自带抽取滤波，像挂了颗 codec）。PDM 是最「嵌入式」的一种：一根时钟下去，一根数据回来， 码流里 1 的密度就是瞬时声压——拖动幅度滑块，看 ΣΔ 调制器怎么用 1bit 表达正弦。

MEMS 模拟ANALOG OUT差分

振膜电容 → 内部放大器 → 模拟电压。差分输出去 ADC 差分输入可白拿 6dB SNR、抵消电源共模。代表：ICS-40300、SPK0838HT4H。适合已有音频 ADC/codec 的板子。

V = Sens × p · 全差分 → 共模抑制
MEMS PDMPULSE DENSITY两线

内部 ΣΔ 调制器输出 1bit 流：声压大 → 1 的密度高。主控给时钟、收数据，低通抽取 64× 成 PCM。抗干扰强（数字传输）、走线短即可。代表：SPH0641LU4H、MP23DB01。注意多数严格 1.8V 供电。

密度 = (1 + x)/2 · x 为归一化声压

I2S

I2S 数字麦帧格式

WS / BCK / SD
I2S 帧三线：WS 选左右声道（麦克风通常只占一个声道，另一个恒为静音数据）、BCK 位时钟、SD 数据。24bit 有效数据左对齐在 32bit 槽里。SPH0645 的 MSB 比 Philips 标准晚一个 BCK，STM32 上要么用 SAI 的 MSBJUSTIFY 模式、要么软件右移一位——不然永远是 2 倍幅度的错位噪声。
SIGNAL

PDM vs PCM 一图流

DENSITY = AMPLITUDE
PDM 的信息在密度不在边沿：0V ↔ 50%，+满幅 ↔ 100%，−满幅 ↔ 0%。所以示波器上看 PDM 像乱码是正常的——它是给滤波器看的，不是给人看的。抽取率 64× 意味着 2.4MHz 时钟出 37.5kHz 采样率，带宽 ~18kHz，刚好覆盖可听域。

指向性与频响实验室 · 它听见哪个方向

Polar & Response Lab

全向（omni）麦克风对四面八方一视同仁；心形（cardioid）正面灵、背面死——0.5×(1+cos θ) 这条玫瑰线就是「歌手话筒背对监听音箱」的全部秘密。 切换指向图案、拖动声源角，读出每个方向的衰减；右侧对比 ECM 与 MEMS 的频响差异。

FR

频响 · ECM vs MEMS

FREQ RESPONSE
ECM 低频受振膜张力与耦合 fc（03 节）限制，高频在 6–8kHz 常有谐振小峰；MEMS 靠激光刻蚀的一致性，20Hz–20kHz 平坦、顶端还故意抬 2–4dB（HF roll-up，提升语音明亮感）。语音识别链路优先选平坦的。
NOISE

底噪与动态范围

SNR BUDGET
SNR 65dBA 意味着等效输入底噪 29dB SPL——比深夜卧室还安静 10dB。但链路里任何一处增益不足的环节都会把这 65dB 白白扔掉：第一级放大器噪声直接加进总账，这就是「麦克风之后第一颗运放要挑低噪」的原因（常用 LMV721/AD8605，噪声 <10nV/√Hz）。

/* ECM + 2.2k 偏置 → A0 · 工作点约 2.3V */
const int N = 256;
int baseline = 0; /* 上电时环境安静段的 ADC 基线 */
void setup(){
Serial.begin(115200);
long s = 0; /* 前 500 次取均值当基线 */
for (int i = 0; i < 500; i++) s += analogRead(A0);
baseline = s / 500;
}
void loop(){
long acc = 0; /* 平均绝对值 ≈ 粗声级 */
for (int i = 0; i < N; i++) acc += abs(analogRead(A0) - baseline);
Serial.println(acc / N); /* 阈值判断声控灯够用 */
}

偏置电阻漏接 / 接错位置

两脚 ECM 的 JFET 要从输出脚经 Rbias 到 VDD 蹭电，另一脚接地。Rbias 没接、或把它接到 GND 侧——FET 没电，输出恒 0。 万用表先量输出脚直流：健康工作点在 VDD 的 0.5–0.8 倍（03 节计算器），读 0V 或 VDD 都是偏置网络断了。

输出
一条死线
直耦把直流放大到顶轨

省掉耦合电容把 ECM 输出直接接进高增益放大器：2.3V 直流 ×8 = 18V，单电源输出直接钉死在轨上（04 节场景②）——示波器一条 3.1V 直线， 什么交流都看不见。Cout 隔直 + 下级重新偏置到 VDD/2，两个元件救回整条链。

大声
破音
增益预算超了 ADC 满量程

110dB 近讲 + −38dBV 灵敏度 + 60dB 增益 = 峰值 3.6V，3.3V ADC 直接削顶（04 节场景③梯形波）。用 03 节计算器按最大预期声压反推增益， 留 6dB 余量；或选带 AGC/压缩的 codec（WM8960 类）让芯片替你动态调。

声音
闷/发虚
耦合 fc 卡在频段中间

0.1µF 进 10kΩ 的高通 fc = 159Hz——人声基频男低 85Hz、女声 165Hz 全被压掉 3dB 以上还附赠相位扭转。要么加 C 到 1µF+， 要么提高 Rin。低频「有但虚」多半是 fc 落在了 100–300Hz：fc = 1/(2π·Rin·Cout) 一算便知。

ADC
读数漂
源阻抗超过 ADC 采样保持的胃口

MCU ADC 要求源阻抗 <10kΩ（采样电容充不满读数就漂）。ECM 输出阻抗 ≈ Rbias 且随信号摆动，10kΩ 偏置直连 ADC 是重灾区。 加一级运放跟随器（阻抗降到 Ω 级）或换 100k 输入的 SAR 前端；也可以牺牲采样率换长采样时间。

嗡嗡
工频声
电源纹波与共模噪声全额进链

50Hz/100Hz 线状谱 = 电源（USB 五毛线尤其脏）或地环路；全频段隆起 = 模拟地与数字地混走。对策按序：Rbias 的 VDD 加 RC 去耦（100Ω+10µF）、 模拟地单点汇流、换差分 MEMS 让共模在接收端抵消（04 节场景④的 ×2 改善就是这么来的）。

PDM
无数据
时钟没喂 / 电压不对 / 线接反

PDM 麦没有 CLK 就是死器件：查主控时钟输出（1–4.5MHz）、查 CLK 与 DATA 是否弄反（示波器上看谁是你自己输出的）。 部分型号（MP23DB01 等）供电严格 1.8V，接 3.3V 轻则畸变重则永久哑——买料时把 VDD 列为第一筛选项。

装上
板就聋
声孔被 PCB 封死了

底部进声孔（bottom-port）MEMS 要求封装正下方 PCB 开孔通到后腔，声孔被阻焊层/铜皮/外壳封住 = 物理性耳聋。 布局时先定声孔位置再走线；顶部进声孔（top-port）则要保证外壳开孔对准且留 0.5mm 以上气隙。改版比改电路贵多了。
