01

为什么需要稳压

Why Regulate

一句话：输入的现实与负载的要求之间隔着一条必须被填平的沟——电压会漂、会抖、会叠纹波，而数字与模拟电路只认一条平直的轨。填沟的器件就是稳压器（regulator）。

看输入侧的现实：锂电池满电 4.2V，放电平台一路滑到截止 3.0V——同一颗电池，早上和晚上电压差 30%； USB 口规范允许 4.5–5.25V（差的线缆加负载还会更低），插上充电器纹波几十 mV 起步； 12V 适配器空载能飘到 13V。没有哪条输入轨天生适合直接供电。

再看负载侧的要求：MCU 的 3.3V 轨典型容差 ±3%（3.20–3.40V），超了轻则复位重则损伤； SoC 内核要 1.2V 甚至 0.8V 且随主频动态调（DVFS，09 节）； ADC/RF 前端这类模拟节对纹波敏感，mV 级毛刺直接进采样结果（见 电容页的去耦、运放页的电源抑制）。

中间的填沟者分两派：LDO（低压差线性稳压器）像一只由误差放大器牵着的可变电阻， 多余电压全部变成热——安静、便宜、无纹波，但效率近似 η ≈ Vout/Vin； DC-DC 开关稳压器像快递员，把电荷打成包按占空比搬运——效率 85–97%，但开关动作本身产生纹波与 EMI。 实际产品几乎总是两者混搭：Buck 做粗调，LDO 给敏感节做最后一公里净化。

把这些轨画在一张图上就是电源树（power tree）：电池/USB 双输入 → 或ing 选择 → 各轨变换 → 各负载。 树怎么长、先给谁上电，是 07 节实验室的主题；本节先建立全页的物理模型底座： 电阻的欧姆定律决定损耗、电容的储能决定纹波、 电感的伏秒平衡决定 Buck/Boost 的一切——本页是它们合流的终点站。

LDO 与 Buck 的一句话分工

TWO ROUTES
同一份 5V→3.3V：LDO 把 1.7V×电流全部烧成热量（效率被拓扑锁死在 66%），Buck 只花导通与开关的零头（95% 上下）。反过来，给 ADC 供 3.3V 模拟轨时 Buck 的开关纹波是毒药，LDO 的 PSRR 是解药——没有更好的那一方，只有放对位置的那一方，06 节把这条分界线画成可扫的曲线。
FACT / A

「稳压」稳的是闭环，不是器件 FEEDBACK LOOP

一切稳压器的内核都同构：基准（带隙 1.2V 左右）+ 误差放大器 + 调整元件。输出经分压与基准比较，误差放大器驱动调整管（LDO 的功率管 / Buck 的 PWM 占空比），把输出钉在 Vref×分压比上。负载电流突变时环路带宽决定恢复速度——这正是 03/04 节实验室里你可以亲手拖动的东西，也是运放页（虚短虚断）负反馈思想的电源版。

FACT / B

压差 Vdo 是 LDO 的生死线 DROPOUT

调整管需要一点「呼吸空间」：输入比输出至少高 Vdo，环路才成立。经典 NPN 结构（AMS1117）Vdo≈1.1V@800mA——3.3V 版本输入必须 ≥4.4V，接锂电池（3.0–4.2V）根本进不了稳压区；CMOS LDO（ME6211 类）Vdo≈100mV，3.5V 电池就能稳稳输出 3.3V。Vdo 还随电流涨，03 节的传输曲线把它画成三区：稳压 / 边缘 / 跟随。

FACT / C

Buck 的一切来自伏秒平衡 VOLT-SECOND

稳态下电感一个周期内「充上的伏秒」必须等于「放掉的伏秒」（否则电流无限累积）：导通期 (Vin−Vout)·D·T = 关断期 Vout·(1−D)·T，移项即 D = Vout/Vin。Boost 同理得 Vout=Vin/(1−D)。这条平衡也是 电感页的核心结论——本页 §04 实验室的锯齿波与三角波就是它在示波器上的长相。

FACT / D

上电顺序错 = 器件报废 LATCH-UP

多轨 SoC 的 IO 电平由 3.3V 轨定、内核由 1.2V 轨定。若 IO 轨先于内核上电，IO 保护二极管会把电流倒灌进未上电的内核阱，触发寄生晶闸管——latch-up，大电流直通，冒烟。所以 PMIC 用 PG（power good）信号菊花链逐级放行下一轨，最后才释放 MCU 复位。07 节实验室把这条时序做成了可步进的状态机，错误顺序的后果也会演给你看。

线性家族按调整管分三代：标准 NPN（78xx/LM317，Vdo 2V 级，便宜耐高压）、准 LDO（PNP，Vdo 0.5–1V，但需要输出电容的 ESR 落在稳定窗口）、CMOS LDO（Vdo 可低到几十 mV，静态电流 µA 甚至 nA 级，配 MLCC）。共同点：输出永远是输入的「削足适履」，效率天花板就是 Vout/Vin。

开关家族按能量搬运方向分：Buck 降压、Boost 升压、Buck-Boost（输入跨过输出上下都能稳）、反激（加隔离，小功率离线电源主力）、电荷泵（用飞跨电容搬电荷，无电感，小电流倍压/反压最省）。共同点：靠占空比控制能量包大小，损耗只剩开关损耗与导通损耗。

基准是只管「准」不管「力气」的一族：带隙基准（bandgap）把三极管 Vbe 的负温度系数与 PTAT 电流的正温度系数对消，得到 ~1.2V 温度稳定的电压——TL431 是可调并联基准的世纪常青树，REF30xx 系列给 12 位以上 ADC 当参考。每颗 LDO/Buck 内部都藏着一个带隙（hero 动画里画了它）。

PMIC 与模块是把整棵电源树装进一颗芯片或一块可焊接模块：多路 Buck/LDO + 上电时序 + PG/复位 + 看门狗 + 热保护。SoC 类芯片（RK/RPi/IMX）的参考设计几乎都围绕一颗 PMIC 展开——09 节 DTS 里的子节点就是它。

选型第一问永远是拓扑，不是型号：压差多大？电流多大？要不要隔离/升压/反压？噪声多敏感？——先在家族表里圈出 2–3 行，再看具体型号的 Vdo、fsw、封装热阻。 11 节的决策树把这条思考路径画成了流程图，本页 03–08 节的实验室则把每一行背后的物理各自拆开。

Buck 稳态的一切由一条守恒式决定：(Vin−Vout)·D·T = Vout·(1−D)·T，即 D = Vout/Vin——与负载电流无关（CCM 下）。 误差放大器全部的工作就是把锯齿交点维持在这个 D 上：你拖高 Vout 目标，vc 上抬 → PWM 变宽 → 输出爬升 → 反馈追上 → vc 回落，四 pane 里看得一清二楚。 电流小到 Iout < ΔIL/2 时三角波触底，进入 DCM——占空比不再等于 Vout/Vin，而要按能量收支重算（公式见 08 节）。

Boost 升压实验室

Boost Cycle Lab

Boost 的关键词是「能量打包搬运」：开关合上——二极管截止，电源只顾给电感充磁，输出全靠 Cout 独自撑着； 开关断开——电感电流不肯突变，经二极管把 Vin+VL 泵向负载并给电容补货。每个周期打一个电荷包，稳态读数 Vout = Vin/(1−D)。 电感页 §07 已做过 Boost 的数值仿真；本页换视角：逐周期动画 + 闭环稳压如何靠调 D 把 Vout 钉住。

Boost 输出永远高于输入，代价是输入电流连续、输出电流断续（斩波），所以 Boost 的输出纹波天然比 Buck 难压——Cout 要更大。 还有一条新手常栽的坑：Boost 输出没有「断路」能力——即使芯片关闭，Vin 仍会经电感+二极管直通到输出（Vin−VF）， 想真正切断负载得加输出开关或背靠背 MOSFET。D 拖到 0.8 时注意 Vout=Vin/(1−D) 趋于发散：真实器件会先撞上开关耐压与二极管反向恢复的墙。

PG 菊花链 · 正确时序

POWER GOOD
PG（power good）是稳压器的自检输出：输出达到目标的 90–95% 并稳定后置位。把它接到下一轨的 EN，就形成菊花链——任何一级没起来，后面全部被拦住，复位信号永远等到全树就绪才释放。硬件上零软件成本，是 PMIC 内建时序的等价手工版。
LATCH-UP

时序错误 · IO 先于内核

WRONG ORDER
SoC 的每个 IO 内部都有接到两轨的保护二极管/结构。IO 轨先上电而内核为 0V 时，IO 引脚上的高电平会经保护结构向内核阱倒灌，触发寄生的 PNPN 晶闸管——一旦触发，电源到地近似短路，唯一的解法是断电。这也是 datasheet 里「最大 IO 电压不得超过内核+0.3V」的由来，以及上电时序必须内核在前的物理原因。

DVFS 就是把本页 §03 的滑杆交给内核：cpufreq 的 opp-table 里每一档频率对应一组电压（频率越高、晶体管翻转越快、需要越高电压）， governor 决定何时升降频，regulator 子系统负责把 PMIC 真正拧到目标电压并等 ramp-delay 走完。 regulator-min/max-microvolt 是你在 DTS 里给内核画的护栏——超出 opp 表的请求会被框架直接拒绝，这正是 01 节「负载要求」在操作系统层的表达。

踩坑指南 · 症状 → 病因

Pitfalls

电源问题的麻烦在于症状常出现在别处：MCU 复位、ADC 跳码、WiFi 掉线——最后查回来都是稳压器或它的外围。八条高频坑，按「症状 → 病因 → 药方」排列。

烫手
热保护
AMS1117 高压差大电流 = 小暖手宝

5V→3.3V@800mA：P=1.7V×0.805A≈1.37W，SOT-223 θJA≈90°C/W → 结温飙升过 125°C，进入热保护反复关断，输出锯齿状掉电。药方：压差×电流 > 0.5W 就换 Buck；必须 LDO 时给铜箔散热、降电流，或两级降压（先 Buck 后 LDO）。

啸叫
可闻噪声
Buck 轻载啸叫（audible noise）

轻载进入 DCM 或跳周期（pulse skipping）模式后，有效开关频率掉进 20Hz–20kHz 人耳频段，电感磁致伸缩+陶瓷电容压电效应把电流变化变成声音。药方：选带 audio-skip-mode 抑制的型号、负载太轻时改小电流 LDO、换一体成型电感（molded）与非铁电介质电容。

负载瞬态
电压跌落
瞬态跌落 → 输出电容 ESR / 环路带宽不够

MCU 从睡眠瞬间唤醒，电流阶跃 5→300mA，环路要几百 µs 才反应，中间全靠输出电容顶住：ΔV ≈ ΔI·ESR + ΔI²·L/(2·Vheadroom)。ESR 大的钽/电解电容让第一项超标。药方：低 ESR MLCC 并联组（考虑直流偏置降容！）、提高环路带宽、必要时加大 Cout。

MCU
无故复位
输入电容离引脚太远 → 输入振铃吃掉余量

Buck 的输入电流是方波，输入引线电感与电容谐振，SW 导通瞬间 Vin 引脚处实际电压可能比电源低零点几伏——5V 系统瞬态跌到 4.3V 以下，MCU 复位阈值一碰就倒。药方：10µF+100nF 尽量贴近芯片 Vin/PGND，输入走线短而宽，必要时加磁珠+第二级电容。

EMI 超标
干扰射频
大电流回路铺铜成天线 · SW 节点成辐射源

Buck 的 hot loop（Cin→上管→SW→下管→Cin）面积每大一圈，辐射效率就高一分；SW 节点 dv/dt 极大，铺一大片铜等于给全板发广播。药方：输入回路面积压到最小、SW 走线只求短不求粗、多层板内层完整地平面、射频敏感板选扩频(fsw dithering)型号。

随机
启停
EN 脚悬空

不少稳压器 EN 无内置下拉（或高阻），悬空时耦合噪声决定开关机——板子「有时能开有时不能」「手靠近就好」。药方：查 datasheet 的 EN 逻辑，不用的 EN 按极性上拉/下拉到确定电平（典型 100k），需要时序控制的接 RC 或 PG 链（07 节）。

启动
振荡
LDO 输出电容缺失 / MLCC 直流偏置降容

老准 LDO 依赖输出电容 ESR 参与补偿：上电瞬间 Cout 从 0 充电，环路相位裕度不足直接振荡；MLCC 的实际容值随直流偏置下降 30–60%，22µF 标称可能只剩 10µF。药方：按手册给的最小 Cout 与「稳定 ESR 窗口」选件、容值按降容后校核、新型 CMOS LDO 选「任意电容稳定」型号。

轻载
纹波变大
PFM 省电与纹波的取舍

高效 Buck 轻载自动进 PFM/DCM：跳周期省了开关损耗，但每包能量不变、包间隔拉长 → 低频纹波明显增大，ADC 可能采到跳变。药方：模拟敏感场合选强制 PWM（force-continuous）模式（牺牲轻载效率）、或 Buck 后串一颗 LDO 做净化（两级架构，06 节结论）。
