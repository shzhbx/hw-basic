01

它是什么，为什么需要它

What & Why

一句话：电阻是把「电流大小」变成「可控电压差」的元件——V = IR 这条直线，撑起了电路里一半的设计技巧。

电阻器（Resistor）是二端线性元件：两端电压与流过电流成正比，比例系数就是阻值 R， 单位欧姆（Ω = V/A）。微观图像是：载流子在导电材料中不断被晶格与缺陷散射， 定向漂移被「摩擦」减速，电能随之变成热——所以电阻永远在发热，功率 P = V·I = I²R = V²/R。

实物用「电阻率 ρ」不同的材料做成：铜 ρ≈1.7×10⁻⁸ Ω·m 太低，做电阻要极细极长； 工程上用碳膜、金属膜、金属氧化物、合金线这些 ρ 高 2~4 个数量级的材料，镀/绕在陶瓷基体上， 再用螺旋刻槽切断部分导电路径来微调阻值——刻槽越多，电流路径越长越窄，阻值越大。

它在电路里反复扮演五类角色：限流（LED、MOS 栅极）、分压（ADC 采样、偏置点）、 上下拉（总线、GPIO 默认态）、端接匹配（CAN/RS-485/高速线的传输线反射）、 电流采样（mΩ 级 shunt 把电流变成可测电压）。选对阻值是欧姆定律， 选错功率、温漂、寄生参数才是真正的坑——这些在 05 节与 09 节展开。

FACT / A

Ω 的出身 1827

欧姆发表 V∝I 时用的是伏打电池与验电器；今天 1 Ω = 1 V/A。电阻率量化材料「难度」：R = ρ·L/A——同材料，越长越细阻值越大。

FACT / B

最直的电阻 RK = h/e²

量子霍尔电阻 RK ≈ 25 812.807 Ω 只依赖基本常数，是 SI 电阻基准。实验室里最「直」的实物电阻是箔式：±0.005%、温漂 0.2 ppm/°C 级。

FACT / C

0 Ω 电阻真的存在 JUMPER

贴片 0 Ω 实为 ≤20~50 mΩ 的导体，却有额定电流（0603 约 1 A、0805 约 2 A，以手册为准）。当跳线、预留选配、单点接地全靠它，见 07 节。

FACT / D

BOM 之王 30%+

一块普通电路板上电阻常占元器件总数三成以上，单价最便宜；但上下拉取错、采样温漂、端接遗漏这些「电阻问题」在调试桌上从不过时。

家族与制造工艺

Family & Process

同样标 10 kΩ，怎么造的决定了精度、温漂、噪声、抗脉冲能力与价格。直插看膜材，贴片分厚膜/薄膜。

碳膜CARBON FILM · CF廉价

陶瓷基体上高温沉积碳膜，螺旋刻槽调阻值。四环 ±5% 起步，温漂大（±250~1000 ppm/°C）、噪声高。如今多被厚膜贴片取代，维修老设备仍常见。

±5% · TCR ±250~1000 ppm · 噪声大 · 直插 1/4 W 起步
金属膜METAL FILM · MF精密通用

真空蒸发镍铬合金膜，均匀致密。五环 ±1%/±0.5%、温漂 ±50 ppm、低噪声——直插世界里精度与价格的甜点，蓝色漆包是它的招牌。

贴片丝印与 E 系列

SMD Markings

贴片电阻太小，印不下色环，于是有了数字丝印三套记法；而阻值本身也非任意值——全世界只生产 E 系列标准值 × 10ᵏ。

3 位

三位码 · ±2%~5%

E24
前两位是有效数字，第三位是10 的幂：472 = 47×10² = 4.7 kΩ；103 = 10 kΩ；000 或 0 = 0 Ω 跳线。配套容差 ±5%（E24）。
4 位

四位码 · ±1%

E96
三位有效数字 + 幂：1002 = 100×10² = 10 kΩ ±1%；4991 = 4.99 kΩ（E96 精确值）。0603 以上才印得下四位。
R

R 记法 · 小数点

Ω CODE
R 顶替小数点：4R7 = 4.7 Ω；0R1 = 0.1 Ω；R047 = 0.047 Ω（mΩ 级 shunt 常见）；0R = 0 Ω。
E96

EIA-96 · 1% 专用

CODE + LETTER
两位代码查 E96 表（01=100 … 96=976），字母定幂（Z=×0.001 … F=×100000）：01C = 100×100 = 10 kΩ ±1%。0603 以下高精度全靠它。
DECODED · 解码结果10 kΩ三位码 · E24 · ±5%
为什么阻值「不连续」：E 系列按 10^(n/N) 等比分布——E24 相邻值差约 10%，恰好覆盖 ±5% 容差带； E96 差约 1%，覆盖 ±1%。所以 4.7 k 之后是 5.1 k 而不是 4.8 k。 需要非标准值时，用两个标准值串并联凑，或上可调电阻。

功率降额曲线

DERATING
降额的物理原因：电阻自热 + 环境温度共同决定膜层温度，超过极限后阻值漂移加速、寿命骤减。 密闭外壳、无风、多电阻扎堆都会推高局部温度——按最热点而非室温做降额。

07

特殊电阻器件

Beyond Fixed R

阻值「会变」或「身兼多职」的电阻家族：调节的、感温的、保护的和计量的。它们共享欧姆定律，却各怀绝技。

VAR / A

电位器 POT

滑动抽头把电阻变成连续可调分压器（分压接法）或可调电阻（变阻接法）。面板旋钮、模拟调零都靠它；磨损后噪声大，数字时代多被 DAC 取代。

VAR / B

热敏电阻 NTC / PTC

NTC 温度升高阻值下降：测温（配合 ADC 查表）与上电浪涌抑制（串在电源入口，冷态高阻限流）。PTC 相反：过流自发热→阻值骤增，就是「自恢复保险丝」。

VAR / C

压敏电阻 MOV

电压超过阈值后阻值瞬间崩塌，把浪涌能量旁路掉——电源入口雷击/浪涌防护的第一道门。每次动作都会老化，与气体放电管、TVS 配合组成多级防护。

VAR / D

光敏电阻 LDR

光照越强阻值越低（亮 kΩ 级、暗 MΩ 级）。配合定值电阻分压即可做光控开关；响应慢（ms 级）、个体差异大，精密测光请用光电二极管。

NET / E

排阻网络 NETWORK

一个封装里 4~8 只同值电阻，共端或分立。总线匹配、LED 驱动、上拉阵列用它：省贴片位、阻值天然匹配（同晶圆批）、温漂一致——比单颗电阻更适合差分/并联通路。

NET / F

保险电阻 FUSIBLE

正常时是电阻（兼限流/隔离），过流到阈值时像保险丝一样可控熔断。电源输出、适配器里常见；色环常为一个色环或标注阻值+熔断特性。

SENSE / G

采样电阻 SHUNT

mΩ 级锰铜/康铜合金，串入电源路径把电流变成压降（满量程常取 50~100 mV）送电流计或 INA 类放大器。必须四线（Kelvin）连接，否则焊盘铜箔的 mΩ 寄生会淹没读数。

JUMP / H

零欧电阻 0 Ω

「会过流的跳线」：替代飞线跨线、预留选配位、模拟地/数字地单点连接、方便断链调试。注意它有最大电流（0603 约 1 A、0805 约 2 A），大电流请用铜箔或专用 shunt。

R₁ = 5.0 kΩ R₂ = 5.0 kΩ VOUT = 2.50 V

读数偏小
并联支路分流 · 表量的是网络不是电阻

IC 输入脚、其他到地路径与被测电阻并联，读数必然偏低。脱开一脚或抬起一端再测；带电路上严禁用电阻档（会伤表并读错）。

上拉
乏力
阻值过大 · 上升沿被 RC 拖慢

t_r ≈ 0.85·R·C：400 kHz I²C 挂 10 k 上拉，长线上直接起不来振。降到 2.2 k 一档；也别盲目太小——灌电流 3.3V/R 会顶到驱动管极限。

高频
不欧姆
寄生电感作祟 · 绕线最重、刻槽次之

实际阻抗 Z = R + jωL：10 nH 在 100 MHz 就有 6.3 Ω「虚阻」。射频与快沿场合选薄膜无感/倒装，绕线一律回避；端接电阻优先 0402 小封装降寄生。

阻值
逐年变大
端电极硫化 · Ag + H₂S → Ag₂S

贴片端电极的银层在含硫气氛（橡胶、工业废气、温泉…）里生成硫化银，阻值缓涨直至开路。外观发灰发黑。工业/户外设计选抗硫化型（金字或 S 后缀）。

采样
乱跳
没做四线 · 焊盘铜箔也是 mΩ

10 mΩ 的 shunt，一段 5 mm 宽的铜箔就有几个 mΩ，走线一改读数就变。电流路径与检测路径必须在焊盘处分开（Kelvin），并做差分走线到放大器。

色环
读反
容差环认错端 · 4.7k 读成 5.1k

金/银环必为容差；容差环与其他环间距更大（有时还更宽）。从数字环一端起读。五环电阻第三位有效数字最容易漏看，棕黑黑红棕 = 10 k 而不是 1 k。

0Ω 跳线
发烫
0 Ω 也有额定电流 · 它是 20~50 mΩ 的电阻

0603 0Ω 约 1 A、0805 约 2 A（以手册为准）。电源路径拿 0402 的 0Ω 过 3 A，压降不大但功耗 I²R 全变成热。大电流用宽铜箔、专用 shunt 或直接 1206/2512。
