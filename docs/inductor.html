01

它是什么，为什么需要它

What & Why

一句话：电感是把「电流变化」变成「电压」的储能元件——V = L·di/dt 这条定律，是开关电源、LC 滤波与 EMI 治理共同的地基。

电感器（Inductor）是二端储能元件：导线绕成线圈，电流流过时在磁芯与周围空间建立磁场，靠磁场储存电能。 感量 L 的定义同样朴素：每安培电流能链住多少磁通，L = Φ/I，单位亨利（H = Wb/A）。 一旦电流试图变化，磁通跟着变，线圈就感应出电动势反抗这种变化（法拉第定律 + 楞次定律）—— 这就是 V = L·di/dt。

这条定律是整页的灵魂：电感上的电压不取决于电流多大，而取决于电流变化多快。 稳态直流下 di/dt = 0，电感电压为零、只是一段导线；而电流的任何突变都需要无穷大的电压—— 电感电流不能突变（否则感应出无穷大反电动势）。与电容对照就是一张对偶表： 电容稳电压、电流可跳；电感稳电流、电压可跳。理想电感不耗散，½LI² 存进磁场，断电瞬间又原样吐回电路——开关电源的升降压、继电器的续流二极管、汽车的点火线圈，全是这一吐的戏法。

它在电路里反复扮演这些角色：储能搬运（Buck/Boost 里逐周期存取能量）、平滑滤波（LC 输出滤波、纹波抑制）、 谐振选频（LC tank、RF 匹配）、噪声吸收（磁珠把高频变成热）、共模抑制（CMC 拦干扰放信号）、 能量传递与变换（变压器、电流互感器）。电阻页讲「限与分」，电容页讲「稳与时」，本页讲「流与磁」。

FACT / A

法拉第与亨利 1831–32

法拉第用线圈与磁铁证明「磁通变化生电」（1831）；大洋彼岸的亨利更早观察到自感现象却没抢先发表——定律归了法拉第，单位 H 最终归了亨利。你手里每一颗电感，都是这两个人的一次握手。

FACT / B

1 H 有多大 E = ½LI²

1 H 的扼流圈是拳头大的铁芯绕组；手机 Buck 里的功率电感只有 1–10 µH，小如芝麻。从 RF 匹配的 nH 到工频扼流的 H，电感横跨九个数量级——丝印体系因此格外重要（04 节）。

FACT / C

通直阻交 DC PASS

稳态直流 di/dt = 0，电感是导线；对交流 XL = 2πfL，频率越高越像开路——与电容的「隔直通交」互为镜像。电源入口串扼流圈拦高频、放直流，正是这一句的工程版。

FACT / D

点火线圈 BOOST 起源

断开电感电流的瞬间，V = L·di/dt 冲向数十 kV——汽车火花塞靠它点火，Boost 升压靠它把 5 V 泵到 12 V。同一条定律的两面：一个用来打火花，一个用来供电。代价是必须给电流留续流路径，否则尖峰打坏开关。

04

丝印标值与色环判读

Markings & Color Bands

电感丝印以µH 为基准：三位码、R 记法、直读值与电阻电容同形不同基；轴向色环电感与电阻环码一致但单位是 µH；功率电感常无丝印，磁珠印的则是阻抗代码。

3 位

三位码 · µH 基准

EIA STD
与电阻丝印同形不同基：前两位有效数字、第三位 10 的幂，基准是 µH——101 = 10×10¹ µH = 100 µH；100=10 µH；472=4.7 mH。同一个「101」印在电阻上是 100 Ω、在电容上是 100 pF。
R / n

R 记法与 n 记法

DECIMAL
字母顶替小数点，字母本身即单位：4R7 = 4.7 µH（功率电感常见），3N3 = 3.3 nH（RF 薄膜/叠层）；欧式印法 4m7 = 4.7 mH。两位直读如 10 就是 10 µH。
色环

色环电感 · µH 基准

COLOR CODE
轴向色环电感多为墨绿/深蓝本体（电阻是米色），四环含义与 电阻页 的四环一致但基准单位是 µH：前两位有效数字、第三位倍率、第四环容差——金 ±5%、银 ±10%。
丝印

功率电感与磁珠的铭牌

POWER / BEAD
一体成型/大电流功率电感常无丝印（或只有料号缩写），测量靠 LCR（09 节）；磁珠印的常是阻抗代码：601 ≈ 600 Ω @100 MHz——那是阻抗不是感量，别按 µH 解码。

DECODED · 解码结果100 µH三位数码 · µH 基准
单位换算是电感丝印的第一坑：1 H = 1000 mH = 10⁶ µH = 10⁹ nH。三位码永远以 µH 计数，于是 100 µH = 101、4.7 mH = 472； 而功率电感常用 E6 系列——1.0 1.5 2.2 3.3 4.7 6.8 ×10ᵏ µH，所以常见 2.2 µH/4.7 µH/22 µH，却买不到 5 µH。

直流偏置下的感量损失

DC BIAS CURRENT
物理原因：直流偏置把磁芯推向饱和磁通密度 Bs，有效磁导率随之下坠。铁氧体 Bs 高但曲线陡（硬饱和）；合金粉芯每个粉末颗粒独立饱和，宏观缓降。同样 10 µH，铁氧体超流即雪崩，一体成型只是缓缓弯腰——08 节实验室可拖动对比。

经典电路实验室 · 四个必懂的拓扑

Classic Circuits

同一颗电感，接进电路的位置不同就是四种经典：Buck 降压（逐袋搬能量）、Boost 升压（反向尖峰的正面应用）、LC 谐振（能量交换的正弦舞）、磁珠滤波（把噪声变成热）。 切换电路、拖动参数——左边原理图的电流在走，右边示波器的波形在变。

BUCK

降压 = 逐袋搬运能量

STEP-DOWN
SW 闭合时 Vin 给 L 充磁（i 上爬），断开时 L 经二极管续流放磁（i 下滑）——能量按 fsw 逐袋从高压搬到低压，C 把三角纹波滤平。L 由纹波比定：L = Vout(1−D)/(f·ΔIL)，06 节直接算。
BOOST

升压 = 反电动势的正面应用

STEP-UP
SW 闭合把 L 并在 Vin 上充磁储能；断开瞬间电流无处可去、VL 反向叠加在 Vin 上把电荷泵向更高电压：Vout = Vin/(1−D)。输入电流连续、输出断续——与 Buck 正好相反。
TANK

LC 谐振 = 能量正弦舞

f₀ = 1/(2π√LC)
充满电的 C 与 L 接通：电荷流动建立磁场、磁场回落又把电荷推回——能量每半周期在电场与磁场间交换一次，波形是纯纯正弦。损耗（R）决定它响多久：Q 高则窄带选频，Q 低则是一次性振铃。
BEAD

磁珠滤波 = 把噪声吃掉

LOSSY INDUCTOR
磁珠是「故意做损的电感」：高频段阻抗以电阻为主，噪声能量被变成热而不是反射回源或穿过过去。低阻源 + 纯电感 + 电容的组合反而会在谐振点放大噪声——拖动 07 节实验室的损耗滑杆看峰被压平。
对突变像开路 · 对稳态像导线OPEN TO CHANGE · SHORT TO STEADY

这句口诀与电容页的口诀互为镜像：换路瞬间电流不能突变、全部电压落在电感上——串联它得到升压与尖峰（Boost、点火、振铃）； 稳态电流恒定、电压为零——串联它通直流（扼流），并联它抹平电流纹波（LC 滤波、CMC）。 R 的角色见 电阻页，C 的镜像见 电容页——三页合读就是无源三件套的全部。

08

特殊电感器件

Beyond Fixed L

感量「会变」或「身兼多职」的电感家族：去噪的、隔离的、测流的。它们共享 V = L·di/dt，却各怀绝技。

BEAD / A

磁珠 FERRITE BEAD

镍锌铁氧体串在电源/信号线上：直流近乎 0 Ω、高频呈现数百 Ω电阻性阻抗——噪声被吃掉变热。铭牌是 阻抗@100 MHz 不是感量；关注 DCR 压降与额定电流，且不可当储能电感用。

CMC / B

共模扼流 CMC

双绕组对向绕在同一磁芯：差模电流磁通抵消（不饱和、近乎 0 Ω），共模噪声磁通叠加呈高阻。USB、以太网、AC 入口的 EMI 标配，常与 X/Y 电容搭成 π 滤波。

XFMR / C

变压器 / 耦合电感 XFMR

共用磁芯的两套绕组按匝比变换电压电流：反激、正激、隔离通信（CAN 隔离、PoE）都用它。同名端（点）标出绕向——接反就是负压输出甚至炸管（10 节有坑例）。

CT / D

电流互感器 CT

载流导线穿心作为单匝一次侧，二次按匝比输出电流信号（I₂ = I₁/N）：AC 电流检测的零损耗方案。电能表、逆变器、漏电保护全靠它——只测交流，直流用霍尔。

VAR / E

可调电感 VARIABLE

磁芯旋进旋出线圈改变磁路磁阻，感量连续微调。老收音机的中周、LC 振荡器精修、天线调谐都靠它；如今多被变容二极管与数字校准取代，但维修台上仍常见。

MAG / F

网络变压器 LAN MAGNETICS

以太网差分对上的隔离变压器 + 共模扼流：2 kV 隔离、共模抑制、阻抗匹配（100 Ω 差模）。常被集成进 MagJack 网口连接器——网口旁边那坨黑方块就是它。

PFC / G

PFC 升压扼流 POWER CHOKE

铁硅铝/铁粉磁环绕制的 mH 级大电流电感：开关电源功率因数校正的心脏。安匝大、温升高，软饱和材料是刚需——硬饱和磁芯在电流尖峰时会瞬间失感。

3D / H

耦合/双相电感 COUPLED

两相 Buck 的电感互相耦合（反同名端）：电流纹波相互抵消，等效纹波频率翻倍——同样体积下瞬态更快。多相 CPU 供电（每相一颗耦合电感）的标准玩法。

拖动滑杆：铁氧体过 Isat 后雪崩、金属粉芯缓缓弯腰。同一颗「10 µH」，在 5 A 偏置下三家剩的感量天差地别—— 这就是大电流供电偏爱一体成型的原因，也是「标称感量」永远要配一张 L–Idc 曲线读的原因（05 节）。

Buck 电感设计实例 — 12V → 3.3V @ 1A · 500kHz
# 纹波比设计法：D = 3.3/12 = 0.275 · ΔIL = r×Iout = 0.3×1 = 0.3 A
L = Vout(1−D)/(f·ΔIL) = 3.3×0.725/(500k×0.3) = 15.95 µH → 就近选 15 µH
IL_pk = 1 + 0.15 = 1.15 A # Isat ≥ 1.2×IL_pk = 1.4 A（按最坏 Vin 与负载瞬态再留余量）
# DCR 预算：铜损 = 1.15²×DCR；DCR=30mΩ → 40mW 温升可忽略，100mΩ → 130mW 要看布局
# 结论示例：15 µH / Isat 2A / DCR ≤ 40 mΩ 屏蔽绕线，或 15 µH 一体成型（大电流裕量场合）

踩坑指南 · 症状 → 病因

Troubleshooting

电感相关的调试时间几乎都花在下面这些地方。按症状对号入座。

上电
过流
电感饱和 · 感量雪崩电流失控

铁氧体电感超 Isat 后 L 骤降，di/dt = V/L 失控变大，逐周期电流爬升直到触发 OCP 或炸 MOS。按 Isat ≥ 1.2×IL_pk 选，大电流场合换一体成型软饱和，别只看「20 µH 挺大」。

轻载
啸叫
DCM/突发模式 · 磁致伸缩在唱歌

轻载下 Buck 进入断续或跳周期，电感以可闻频率反复充放磁，磁芯形变带动 PCB 振动（1~20 kHz）。提高轻载效率、换低 Buzz 一体成型、加灌胶/支架，或把工作点拉回 CCM。

电压
被吃
DCR 太大 · 压降加发热双杀

大电流路径上串了一颗小体积高 DCR 电感：输出电压随负载下垂（ΔV = I×DCR），铜损 I²R 还在烤它。算清 DCR ≤ ΔV允/I，必要时两颗并联（感量翻倍 DCR 减半再各减）。

EMI
超标
非屏蔽开磁路 · 电感成了辐射器

工字电感/环形半开放磁路把开关噪声直接撒进空间。数字板首选屏蔽型或一体成型；保留开磁路就拉开与天线/晶振的距离，并把 SW 环路面积压到最小（09 节布局三原则）。

噪声
更大了
磁珠 + 电容谐振峰 · 帮倒忙

低阻源 + 低损耗路径上，磁珠感抗与负载电容在谐振点附近 |Z| 谷值形成峰值，噪声不降反升几十 dB。看阻抗曲线选「电阻性为主」的频段，加阻尼电阻或换高损耗磁珠（07 节实验室拖损耗滑杆）。

高频
失配
超过 SRF · 电感变电容

寄生电容在 SRF 处与感量谐振，更高频率呈现容抗——RF 匹配网络移了个寂寞。选 SRF ≥ 10×f_work，小感量、小封装、叠层/薄膜结构 SRF 更高。

读数
对不上
LCR 测试条件不对 · 不是表的错

同一颗功率电感：1 kHz 与 100 kHz 档读数不同（磁芯频散），加不加直流偏置差更多（饱和）。按厂规选频率/电平，比对要同条件；实测偏低先想偏置，再想匝间短接。

反激
反了
同名端接反 · 负压炸管

变压器/耦合电感的绕向由同名端（点）定义，接反后次级相位翻转：反激输出变负压、MOS 承受 2× 应力。原理图带上 dot 符号，绕制与接线按 dot 复核，上电前先示波器空载验证。
