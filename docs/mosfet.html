01

它是什么，为什么需要它

What & Why

一句话：MOSFET 是用电压控制电流的阀门——三极管要持续的基极电流才肯干活，MOSFET 只要一个电压就位、几乎不取电流；栅极与硅之间隔着一层玻璃（SiO₂），这是它与 BJT 的全部身世之别。

MOSFET（Metal-Oxide-Semiconductor Field-Effect Transistor，金属-氧化物-半导体场效应晶体管） 由金属栅极、氧化层绝缘、半导体衬底三层叠成，引出三个电极：G（Gate 栅极，控制端）、 D（Drain 漏极，多数电流出口）、S（Source 源极，多数电流入口）。 栅极加电压 → 电场穿过氧化层 → 把衬底里的电子吸到表面形成导电沟道—— 电压把「桥」搭起来，D 与 S 之间才通。栅极与沟道之间是绝缘的氧化层： 输入阻抗 10⁹–10¹¹ Ω，静态栅流 pA 级，驱动它几乎不费电。

与 三极管（BJT）对照着记最快：BJT 是电流阀门——IC = β·IB， 基极必须持续灌电流；MOSFET 是电压阀门——ID 由 VGS 决定，栅极像一只小电容 （Ciss 几百 pF 到几 nF），只在开关瞬间充放电才需要一点电荷（Qg）。 导通物理也不同：BJT 饱和后是一个近恒定的 VCE(sat) ≈ 0.2–1 V， MOSFET 导通后是一只线性电阻 RDS(on)——1 A 电流只产生 ID×RDS(on) = 几十 mV 的压降， 且没有少子存储时间（BJT 的 ts 账单，见 三极管页 08 节），开关频率直上 MHz。

嵌入式工程师的日常几乎都写着它：低边开关（GPIO → NMOS → LED/继电器/马达）、 高边开关与反接保护（PMOS）、PWM 调速调光、电源同步整流、 电平转换（BSS138 双向移位）。电阻页讲「限与分」，电容页讲「稳与时」， 电感页讲「流与磁」，二极管页讲「向与门」，三极管页讲「控与放」，本页讲「场与阻」—— 电场开沟道，沟道即电阻。

FACT / A

1926 年的理论，1960 年的器件 LILIENFELD → KAHNG

Julius Lilienfeld 1926 年就申请了场效应管专利——比晶体管早 21 年，但那时的界面太脏，做不出来。1960 年 Dawon Kahng 与 Martin Atalla 用热氧化硅得到干净界面，贝尔实验室做出第一只 MOSFET。今天一颗 CPU 里躺着上百亿只它的直系后代。

FACT / B

栅极为什么「不取电流」 MOS CAPACITOR

栅-沟之间是一层 5–100 nm 的 SiO₂（玻璃）：直流下它是理想绝缘体，RGS > 10⁹ Ω。所谓「驱动 MOSFET」，只是给这只以氧化层为介质的电容（Ciss）充电——开一次充 Qg（几 nC 到上百 nC），静态电流为零。代价：栅极悬空时电荷无处可去，管子半开不关——下拉电阻由此成为铁律（10 节坑 5）。

FACT / C

mΩ 时代的导通损耗 I²R vs VCE(sat)

BJT 导通损耗 = VCE(sat)×IC（恒压型，0.2–1 V）；MOSFET 导通损耗 = ID²×RDS(on)（电阻型）。10 A 负载：BJT 0.3V×10A = 3 W 发热；MOSFET 5mΩ×10² = 0.5 W——差一个数量级。但注意方向反了的场景：小电流时恒压型反而省（1 mA：BJT 0.3 mW vs MOS 3mΩ… 都很小），而 MOS 在大电流下优势滚雪球。

FACT / D

体二极管：不是缺陷，是身份证 BODY DIODE

功率 MOSFET 是垂直结构，源区 P 型与 N 漂移区天然构成一只寄生的 PN 结——S 为正、D 为负时导通（N-MOS），符号里画在沟道旁边。同步整流干脆直接用它当整流管；但它的存在让 MOSFET 不能像理想开关那样双向阻断——反接保护、H 桥的死区设计，全是围绕它的故事（04 节万用表实验室第一步就是找它）。

02

结构与家族谱系 · 沟道是怎么被电场搭起来的

Structure & Family

MOSFET 的全部魔法压缩在栅极-氧化层-衬底这颗「MOS 电容」里：电压一步步升高，半导体表面从耗尽走向反型——一条由电子铺成的沟道把两个 N+ 岛连起来。步进看完这四步，符号与家族就都通了。

栅压搭桥 · 氧化层绝缘 · 体二极管自带MOS CAP → INVERSION CHANNEL

把 MOS 电容看成可调的「电子水库闸门」：VGS = 0 时 P 衬底里没有自由电子，D-S 之间是两只背靠背的 二极管（不通）；VGS 抬走空穴形成耗尽层；VGS 越过 Vth（阈值电压）， 表面电子浓度超过空穴——反型层出现，这就是「沟道」。此后 VGS 再高，沟道只是更厚更导通 （RDS(on) 更小）。所以：阈值不是「开关点」，而是「沟道开始存在的点」——完全导通需要过驱动（05 节头号误区）。

增强型 N-MOSE-MODE N默认答案

VGS = 0 无沟道（增强=平时关）；VGS > Vth 反型出电子沟道，电流 D→S。体二极管从 S 指向 D（S 是 P 区、D 是 N 漂移区）：S 接高时它先导通。低边开关、功率级上管……绝大多数岗位都是它。

VGS(+) 开 · 体二极管 S→D · RDS(on)@VGS=10V 或 4.5V
增强型 P-MOSE-MODE P高边拍档

镜像兄弟：VGS < 负阈值（VGS = −5V 才开），源极常驻正轨。高边开关、反接保护、缓启动的正端闸门。体二极管从 D 指向 S——反接保护正是先靠它把源极抬起来（07 节场景 ②）。同规格下 P-MOS 的 RDS(on) 约为 N-MOS 的 2–3 倍（空穴迁移率低）。

VGS(−) 开 · 高边无需求自举 · RDS 略高于同级 N
耗尽型D-MODE常通型

当开关用，就要把工作点狠狠推进电阻区（也叫线性区）：VDS 压到几十 mV，导通损耗 = ID²×RDS(on)—— 「合上的开关」是一只电阻而不是一个结。当放大用，就住在饱和区（恒流区）：ID 只听 VGS 的、 几乎不管 VDS——受控电流源，转移特性的平方律就是它的刻度尺。 注意 MOS 的「饱和」与 BJT 的「饱和」恰好是相反的区：BJT 饱合=开关合上，MOS 饱和=电流恒定（更像 BJT 的放大区）。

关键参数 · 数据手册摘读

Key Parameters

九个数定一颗 MOSFET：Vgs(th)、RDS(on)、BVDSS、ID、Qg/Ciss/Crss、SOA、EAS、RθJA、TJ。第一个是新手误读重灾区，中间四个定「能不能用」，最后几个定「用多久、怎么装散热器」。

参数典型值含义与选型要点
Vgs(th)1–4 V阈值：ID = 250µA 时的 VGS——只是沟道「开始出现」，完全导通还要 2–3 V 过驱动。按它选管 = 半开态发烫（10 节坑 1）。
RDS(on)1mΩ–3Ω导通电阻：必须@指定 VGS（4.5V/10V 两档差 1.5–2 倍）；导通损耗 = ID²·RDS(on)。注意它是温度函数，100°C 约为 25°C 的 1.5–1.8 倍（右上图）。
BVDSS20–900 VD-S 击穿电压（G-S 短接时测）。选 ≥ 2× 工作电压；感性尖峰（电感页）单算。
ID (max)0.1–200 A手册值是 TC=25°C 理想散热 下的——靠封装热阻反推实际可用电流（RθJA 行），常只有标称的 1/3。
Qg / Qgd1–150 nC总栅电荷 / 米勒电荷：决定开关速度与驱动损耗（P=Qg·VGS·f）。Qgd 大 = 平台长（08 节）。
Ciss/CrssnF / 百 pF输入/反向传输电容：Ciss 充放电决定边沿，Crss（即 Cgd）是米勒效应的元凶——高压下它等效放大数十倍。
VGS(max)±20 V栅氧化层耐压：超过即击穿（不可恢复）。12V/24V 系统直接驱动要加分压或齐纳保护。
EASmJ–J 级单次雪崩能量：无钳位感性负载的能量账单由它付（07 节场景 ③）。 datasheet「完全表征雪崩」= 允许有界使用。
SOA曲线安全工作区：DC 线在大 VDS 小 ID 角落被「线性区热失控」削掉——MOS 没有二次击穿，但有 Spirito 效应；当线性稳流用必须缩额（坑 8）。
RθJA / TJ0.5–100 °C/W结温 = 环温 + P×RθJA < 150°C（175 上限别贴线）。TO-220 自然冷约 62°C/W → 无散热器 2W 封顶。
两个温度事实：① RDS(on) 随结温 +0.7%/°C 左右——100°C 时约 1.5–1.8 倍，损耗按热态算，否则正反馈发烫； ② Vgs(th) 随温 −3~−5 mV/°C——并联均流、缓启动阈值都受它牵动。热设计永远用热态参数，不用 25°C 的漂亮数字。

经典电路实验室 · 五个必懂的电路

Classic Circuits

同一颗 MOSFET，接法不同就是五种经典：低边 N-MOS 开关（对比 BJT 版）、高边 P-MOS 开关（栅极参考的陷阱）、 感性负载与续流（雪崩的账单）、BSS138 电平转换、PMOS+RC 缓启动。切换场景与模式——原理图的电流在走，右边的波形在算。

低边 N 管最好驱 · 高边 P 管看参考GATE REFERENCE IS EVERYTHING

MOSFET 只认 VGS = VG − VS：低边开关的 S 接地，栅极电平就是 VGS，GPIO 直接驱； 高边 P-MOS 的 S 在正轨上，栅极必须以 S 为参考——经电阻拉到地（VGS = −Vbat 导通）、经电阻拉回 S（VGS=0 关断）。 「栅极接电池正极」这类错误会让 VGS 恒等于 0，管子永远假装关断（或假装导通，取决于初始电荷）。 更高的正轨高边，用 N-MOS + 自举驱动器——那是 Buck 变换器的世界。

米勒平台与开关时间实验室

Miller Plateau Lab

开通不是一蹴而就：栅压先爬到阈值（td）→ 电流接手（上升）→ 电压下降时 Crss 等效放大、栅压被「钉」在平台（Qgd 账单）→ 过驱动充电。 平台电压 = VGS(th) + ID/gm，与模型跨导自洽；拖动 Rg 看斜率与平台时长怎么变——开关损耗（06 节）就从这里长出来。

测试：VDD 12V · ID 5A · VGS 10V · Ciss 1.5nF · Qgd 12nC
WHY

平台为什么是「坑」

Cgd × AV
VDS 从 12V 掉到 0 的瞬间，漏极 dv/dt 经 Crss(Cgd) 反馈回栅极：等效电容 = Crss×(1+AV) 被放大几十倍，驱动电流全去填这只「无底洞」，VGS 停在 Vpl 纹丝不动——直到 VDS 落地。平台时长 = Qgd / Ig，Rg 越大越长。
LOSS

开关损耗就发生在平台

VI OVERLAP
开通/关断各一次电压电流交叠：Psw = ½·VDD·ID·(tr+tf)·fsw（06 节公式）。20kHz 以下开关损耗常可忽略；上到几百 kHz，它反超导通损耗——那时 Rg 要小、驱动器要硬、甚至上 GaN。栅极损耗 Pg = Qg·VGS·f 与 Rg 无关（电荷搬家是必然），Rg 只决定「搬多快」。

踩坑指南 · 症状 → 病因

Troubleshooting

MOSFET 的调试时间几乎都花在下面八个地方。按症状对号入座。

半开态
发烫
把 Vgs(th) 当「完全导通电压」

Vgs(th) 是 ID=250µA 的测试点：3.3V 驱一颗 Vth=3V 的管子，它停在转移特性膝部当「半开的电阻」——VDS 数伏、P=V×I 直线上升。选管看 RDS(on)@VGS 规格：GPIO 3.3V 驱动必须选 RDS(on)@VGS=4.5V（甚至 2.5V）的逻辑电平管（05 节曲线）。

3.3V 驱
标准管发烫
标准栅管 @ 低栅压的恒流陷阱

IRF530 这类标准栅管（RDS@10V 规格）在 VGS=3.3V 时 β 不足：ID 被钉在饱和区电流上，VDS 高悬、管子当电炉。要么换逻辑电平管，要么加驱动级把 VGS 抬到 10V——中间没有捷径。07 节场景 ① 的读数行就是对比账。

装反
永远导通
体二极管方向装反 / D-S 接反

N-MOS 体二极管 S→D 导通：D/S 接反后，负载电流走体二极管——栅极怎么关都关不掉，还多付 0.7V 压降。判别：万用表二极管档找那只 0.5–0.7 的「结」（04 节实验室），焊前 3 秒救一块板。

高边 NMOS
开不起来
N-MOS 高边无自举 · VGS 不够

N-MOS 源极接负载侧：一旦导通源极被抬到电源轨，VGS=VG−VS 归零，沟道立刻塌回去——「自导通失败」。正解：PMOS 高边（S 常驻正轨），或 N-MOS + 自举驱动器（Buck 的世界）。直接 GPIO 拉高边 NMOS 栅极是永远失败的拓扑。

复位后
负载乱动
栅极悬空 · 电荷无处安放

MCU 复位期间 IO 变高阻，栅极（一只绝缘电容）保持最后的状态——上次导通的电荷还在，管子继续开着；手指靠近都能改变它的状态。铁律：G-S 间 100k 下拉，让悬空默认「关」。数字管时代也别忘了（06 节计算器下拉行）。

感性负载
管子炸了
无钳位断开 · 雪崩超 EAS

继电器/马达线圈断流瞬间 V=L·di/dt（电感页）：VDS 冲上几百伏，管子进入雪崩硬扛——单次能量超 EAS 就永久报废。续流二极管就近反并联在线圈上（07 节场景 ③ 无续流模式的红色尖峰就是事故现场）；高频场合用 RCD 或 TVS 钳位更快。

高频下
莫名发烫
Rg 过大 · 平台时间吃掉周期

Rg 大 → Ig=(Vdrv−Vpl)/Rg 小 → 米勒平台拖长（08 节实验室拖给你看）→ 电压电流交叠时间占比上升 → 开关损耗爆炸。100kHz 以上：Rg 按 tr 目标算（06 节栅阻计算器），驱动器直接挂栅极、电阻只做阻尼（几 Ω 到几十 Ω）。

线性用
热失控
DC SOA 与 Spirito 热不稳

把 MOSFET 当线性调整管（大 VDS + 大 ID 同时存在）：芯片局部热点抢电流、越热越抢——热电正反馈烧一个点，SOA 图右上的「DC 线截止角」就是给它的。LDO 调整管、恒流源场合：按 DC SOA 大幅缩额，或老老实实用 BJT（其 SOA 在线性区更友好）。
