扬声器SPEAKER & BUZZER

电路走到尽头，总要推动一点空气才算闭环。扬声器是唯一的「电动机械」器件： 音圈里的一段导线泡在磁隙中，F = B·I·L——电流一变，锥盆就推拉空气 440 次/秒，你听到的 A4 就在其中。 它反过来又是一只线圈 + 弹簧 + 质量的机械系统：阻抗曲线上的谐振峰、8Ω 标称阻抗背后的 6.8Ω 直流电阻、 喇叭必须装箱才有低音，全都由此而来。 往下滚动：音圈受力实验室、阻抗曲线实验室、声压/功率计算器、蜂鸣器判别树、四个驱动电路实验室、能真正出声的发声实验室。

01

它是什么，为什么需要它

What & Why

扬声器（speaker / loudspeaker）是电声换能器：把电信号变成空气的振动。你写 HAL_TIM_PWM_Start() 那一刻，MCU 输出的还只是电；要让现场工人隔着 3 米车间噪声听见报警，中间必须有人把电流变成声压——这就是喇叭的工作。

动圈式（moving-coil / dynamic）是绝对主流：音圈（voice coil）悬浮在永磁体的磁隙里，馈入音频电流时， 导线受洛伦兹力 F = B·I·L（B 磁通密度、I 电流、L 音圈线有效长度）前后振动， 带动锥盆（cone）推拉空气。电→力→声，两重换能、一个器件。

嵌入式世界更常见的近亲是蜂鸣器（buzzer）：只发单一提示音的「退化扬声器」。 有源蜂鸣器内置振荡芯片，给直流就响，GPIO 一行代码；无源蜂鸣器是裸换能器， 必须喂 2–4kHz 方波——换来的是频率可编程，能播旋律。两者外观几乎一样，接法天差地别（05 节判别树）。

与其他「终端器件」对比：LED 把电流变成光（约 30% 效率），扬声器把电流变成声（典型只有 1–5%）—— 绝大部分功率变成了音圈的热。这也是为什么「小喇叭 + 大功率」的第一死法不是机械损坏，而是音圈烧断。

SPEC · 01

额定阻抗 4 / 8 / 16 Ω

不是直流电阻！是1kHz 附近的标称最小阻抗，直流电阻 Re ≈ 0.85×Znom。功放按它匹配输出电流。

SPEC · 02

灵敏度 dB @ 1W/1m

1 瓦功率、1 米处测得的声压级。小喇叭 82–86dB，高效喇叭 90dB+——差 3dB = 功率差一倍。

SPEC · 03

谐振频率 Fs

音圈+振膜质量与支撑弹簪构成的机械谐振点，阻抗曲线的峰。低于 Fs 的低频发不出声——小喇叭低音差的物理根源。

SPEC · 04

额定功率 P(W)

长期可承受的节目信号功率（粉噪声）。注意 PMPO「峰值音乐功率」是营销数字，可比额定值大 10 倍以上。

三段换能链

ELECTRIC → FORCE → SOUND
音圈同时是「电机」（通电出力）和「发电机」（振动生电）——喇叭纸盆被按动时音圈两端会出现电压，这是低音炮「反电动势」与动圈话筒的共同原理。折环（悬边）与定心支片是弹簧：刚度决定 Fs，太软低音好但冲程失控会「打底」。
WHY

为什么小喇叭没低音

Fs & EQ-LIMIT
低于 Fs，锥盆整体随音圈刚性移动但辐射效率断崖下跌：11mm 微型喇叭 Fs 高达 400–800Hz，所以手机外放没有低音——不是功放不行，是物理不行。对策：装箱（抑制声短路）、倒相管、或数字端直接切除 Fs 以下频段省功率。
03

阻抗曲线实验室 · 8Ω 从来不是 8Ω

Impedance Lab

拿 LCR 表量喇叭：低频读数乱跳、1kHz 附近最小、高频越量越大——因为你量的不是电阻，是 Re + 机械谐振（Fs 峰）+ 音圈感抗（高频上升）的复数阻抗。切换器件看曲线，拖游标读任意频点的 |Z|。

对数频率轴 20Hz–20kHz
峰值 = Re × Q 量级的机械谐振峰（Q 为机械品质因数）；谷点 Zmin 是分频器与功放设计的参考点；高频上升来自音圈电感 Le（|Z| ≈ 2πf·Le）。曲线由小信号模型 |Z(f)| = √((Re + Lorentz(Fs,Q))² + (2πf·Le)²) 实时计算。
量喇叭用电阻档 · 配功放看 ZminRE FOR METERS · ZMIN FOR AMPS

万用表蜂鸣档判好坏，量的是 Re ≈ 0.85 × Znom（8Ω 喇叭量出 6–7Ω，4Ω 量出 3.2–3.6Ω），还伴随「咔嗒」声——那是阶跃电流在推音圈。 功放设计看的是曲线的谷：4Ω 峰值电流是 8Ω 的两倍（P = V²/Z），把 4Ω 喇叭接进 8Ω 额定的功放，轻则保护关断，重则烧输出级—— 反过来 16Ω 喇叭接 8Ω 功放只是「响得小」，安全。

05

蜂鸣器家族与判别树

Buzzer Family

同一个「黑色圆柱、两脚、会响」的外观下藏着四种东西：有源 / 无源 × 电磁 / 压电。 拿到散料分不清时按判别树三步走——先表笔，再直流，后方波。

动圈喇叭SPEAKER全频带

本页主角。能还原音乐，但必须配功放——MCU 引脚的 ±8mA 推不动 8Ω 负载（3.3V/8Ω≈0.4A！）。嵌入式配 5V/8Ω + 一颗 PAM8403 类 D 类功放是标配。

P = V²rms / Z · BTL 桥接摆幅 ×2 → 功率 ×4
有源蜂鸣器ACTIVE / SELF-DRIVEN通电即响

内置振荡芯片 + 换能器，「源」= 自带振荡源。给额定直流电压就响固定音调（约 2.3–3.6kHz），约 25–35mA。有极性：长脚/印字侧为 +，反接不响甚至损坏。适合「一行代码报警」。

GPIO HIGH → 滴——— · 频率固定不可编程
无源蜂鸣器PASSIVE / TRANSDUCER可编程

裸换能器，没有振荡源。必须由 MCU 输出方波驱动，频率 = 音调：2.7kHz 最响（谐振点），800Hz 做低提示、5kHz 做尖锐警告，还能播《小星星》（07 节发声实验室）。比有源便宜，电流相近。

tone = f(PWM) · 50% 占空比方波
压电片PIEZO DISCµA 级

压电陶瓷片，像电容不像电阻：只在边沿有充放电电流，均值 µA 级——小面积片可由 GPIO 直接驱动（06 节场景①）。高阻抗、耐高压，声单薄尖亮；驱动大功率需变压器或电感升压。

06

驱动电路实验室 · 四个必懂的电路

Drive Circuits

从「GPIO 能不能直接推」到「5V 怎么榨出 1.3W」：GPIO 直驱与电流红线、三极管驱感性蜂鸣器与续流二极管（关断尖峰的账单）、 耦合电容为什么不能省（直流进音圈 = 偏移 + 纯发热）、H 桥 BTL 的 ×4 魔法。切换场景与模式——左边的电流在走，右边的波形在算。

感性负载先续流 · 直流隔直再进圈FREEWHEEL & BLOCK THE DC

电磁蜂鸣器和动圈喇叭都是线圈：关断瞬间的电流无处可去，VCE 会冲到电源电压的数倍（本页场景②实测模型 38V）—— 一只 1N4148 反并联在线圈两端，尖峰立即钳到 VDD + 0.7V（MOSFET 页讲过同一件事）。 而单电源功放的输出端有静态直流电位，直接进喇叭就是「不发声、只发热、音圈偏移」三连——所以 OTL 功放输出端永远串一只耦合电容， 容量按 fc = 1/(2π·Z·C) 算（电容页的高通）。

Lab Practice

按选型五步走一遍（点步骤看依据），再抄三个平台的驱动代码：STM32 定时器 PWM、ESP-IDF LEDC、Linux evdev 蜂鸣器与 ALSA 播放。命令可点击复制。

STM32 · HAL TIM PWM
/* 无源蜂鸣器：TIM3_CH1 (PA6) · 50% 占空比方波 */
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
/* 2.7kHz 最响：PSC=0, ARR = 84MHz/2730 - 1 = 30769 */
__HAL_TIM_SET_AUTORELOAD(&htim3, 30769);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 30769/2);
/* 播旋律：节拍定时器里查表跳频率 */
void tone(uint32_t f){
uint32_t arr = (84000000/f) - 1;
__HAL_TIM_SET_AUTORELOAD(&htim3, arr);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, arr/2);
}
tone(262); /* C4 · 小星星第一个音 */
/* 有源蜂鸣器则用普通 GPIO：HAL_GPIO_WritePin(BZ_GPIO, BZ_PIN, SET); */

踩坑指南 · 症状 → 病因

Troubleshooting
完全
无声
有源/无源搞反

给无源蜂鸣器上直流 → 线圈只有直流，不振动，无声且持续发热；给有源蜂鸣器喂方波 → 内部振荡器被打乱，响一半哑一半。先判别（05 节），再驱动。有源蜂鸣器还要查极性：反接的常见结局是永久哑。

声音
很小
小喇叭没装箱 + 驱动摆幅不足

微型喇叭裸放（没有前腔/后腔）时振膜正面推的空气直接绕到背面抵消——低中频掉 6dB 以上。加密封腔体比换喇叭更立竿见影。另一常见原因是拿 SE 单端指标当 BTL 用（04 节：差 4 倍功率），或音量靠 MCU 的 8bit PWM 稀疏量化。

破音
失真
功放削波 / 超功率 / 冲程打底

把 5V 功放开到满音量放重低音：输出削成梯形波（谐波暴增 = 破音），且直流分量开始烤音圈。低频大信号还可能让锥盆冲过 Xmax 撞底「咔咔」响。数字端限幅（软件限至 0.7×满幅）+ 高通滤波（切 Fs 以下）双管齐下。

喇叭
发烫
直流进了音圈

音圈对直流只呈现 Re（约 6.8Ω），2.5V 直流就是 0.9W 纯热——不发声、只烧线圈。排查：单电源功放输出耦合电容漏电/虚焊、BTL 两个半桥失调不对称、MCU 的 PWM 引脚意外输出常高电平驱动了直耦路径。

烧功放
保护
阻抗不匹配

4Ω 喇叭接 8Ω 额定功放：同样电压下电流翻倍（P=V²/Z），轻则芯片过流保护「响一下就哑」，重则烧输出级。多只喇叭并联前先算等效阻抗：两只 8Ω 并联 = 4Ω。反之 16Ω 接 8Ω 功放只是功率减半，安全。

驱动管
频繁坏
感性负载没续流

电磁蜂鸣器/喇叭线圈关断瞬间的反冲可达电源电压 5–8 倍（06 节场景②模型 38V），三极管 VCE 天天被击穿。一只 1N4148 反并联线圈两端（阴极接正轨），尖峰钳到 VDD+0.7V——成本一分钱，返修省一台。
